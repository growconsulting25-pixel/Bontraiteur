# Bon Traiteur

Site public (V1) de Bon Traiteur — service de repas pour CPE, garderies et services de garde.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # build de production
npm run typecheck
```

Voir [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) pour l'architecture, les règles de contenu
et le plan d'évolution vers le portail client (Supabase).

**Avant la mise en ligne**, remplacer les éléments marqués `PLACEHOLDER` / « Photo à venir » /
« Témoignage à venir » / « [À confirmer] » (voir `src/data/site.ts`, `src/data/media.ts`,
`src/data/content.ts`, `src/data/faq.ts`).
